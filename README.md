# 🛡️ 地震そなえナビ

**地域のリスク確認と備えをサポートする防災支援アプリ（デモ版）**

---

## ⚠️ 重要な注意事項

**このアプリは地震予知・地震予報を行うものではありません。**

公的機関等の情報をもとに、地域の地震リスクと日頃の備えを確認するための防災支援アプリです。表示されるリスク数値はデモ用のサンプルデータです。実際の確率は [J-SHIS 地震ハザードステーション](https://www.j-shis.bosai.go.jp/) 等の公式サービスでご確認ください。

---

## 📱 機能

### 1. ホーム画面
- 地域選択（主要都市8箇所のデモデータ）
- 今後30年以内に震度6弱以上が発生する確率（J-SHIS参考値）
- 揺れやすさ（地盤の種類）
- 近くの避難所情報（デモ）
- 備えチェックの進捗

### 2. 地域リスクマップ
- 揺れやすさ分布（デモ用模式図）
- 現在地マーカー（パルスアニメーション）
- 近年の主な地震記録（2024〜2025年）
- 公式情報へのリンク

### 3. 備えチェックリスト
- 13項目の防災チェックリスト（カテゴリ別）
- 準備度の％表示
- カテゴリフィルター
- チェック状態は端末に保存

---

## 🔐 プライバシー・データ

- **個人情報は収集していません**
- データはすべて端末内（localStorage）にのみ保存されます
- サーバーへの送信はありません
- ログイン機能はありません

---

## 🚀 セットアップ

```bash
npm install
npm run dev
```

ブラウザで `http://localhost:5173` を開いてください。
